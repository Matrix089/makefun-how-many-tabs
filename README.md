A tiny Python program that writes one honest tab count, in digits and nothing else, to /output/entry.txt for make.fun's How Many Tabs Do You Have Open? bounty. Top 10 share the $5 prize.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
